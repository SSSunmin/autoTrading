# 시안 v0.6 → 화면 개발 계획 · 기획 차이 · 디자이너 요청

작성 2026-11-13 · 컨트롤 타워. 근거: 디자이너 캔버스 v0.6(아트보드 20장, `mockup/canvas/project/`), `docs/02`(머리말 v0.3 + §11 인용 블록 v0.5·v0.6), `docs/08`, `docs/04`, `frontend/src/` 현재 코드(develop 1db74f9).

## 0. 한 줄 결론

- 시안은 기획서 §11과 docs/08을 전부 반영했고 미국 8장까지 있다. **코드 대비 가장 큰 공백은 화면 8(모의투자 검증) + 실거래 전환 모달, 설정의 실거래 자본·유니버스 미리보기, 공통 컴포넌트(한도 게이지·청산 사유 배지·국면 배지·as-of 스탬프)**다.
- 시안이 **코드와 다른 규칙을 전제한 곳이 4개** 있어 사용자 결정이 필요하다(§2-A).
- 시안 자체의 오류·불일치 23건은 디자이너 수정 요청으로 정리했다(§4 프롬프트 1).
- 개발은 7단계, 전부 `api` 워커(프런트+백엔드). 선행 코어 작업 2개(`us-baseline`, 섹터 조회)는 `core`.
