# 미국장 추가에 따른 화면 요구 정리

작성 2026-11-13 · 컨트롤 타워(개발 세션) → 디자이너 세션 · 상태: 제안(시안 반영 여부는 디자이너가 결정)

## 0. 전제 (사용자 결정 2026-11-13)

- 미국장을 추가한다. **국내장(KRX)과 섞지 않는 별도 포트폴리오**다. 현금 · 노출 한도 · 드로다운 · 모의투자 통과 판정이 시장마다 따로 있고, 환율 환산 합계는 만들지 않는다.
- 코어 쪽은 `core` 워커가 `feature/us-market`에서 진행 중(시장 설정 `config.MARKETS`, 3차 실측 `docs/07`). 실행 레이어 · API · 화면의 시장 축은 그 다음 `api` 워커 작업이다. 이 문서는 그 작업과 시안에 필요한 **화면 요구**만 적는다.
- 결론 먼저: **새 화면은 필요 없다.** 전역 "시장 전환"과 홈의 시장 요약 카드, 설정의 시장별 패널 확장으로 충분하다. 기존 8화면(기획서 §2 · §11-1) 각각에 아래 변경이 들어간다.

## 1. 공통 — 상단바 · 컴포넌트

| 항목 | 요구 | 비고 |
|---|---|---|
| **시장 전환** | 상단바에 `국내 · 미국` 토글. 모든 화면이 선택한 시장 하나를 보여준다(별도 포트폴리오라 섞어 볼 일이 없다). URL에 시장이 남아 새로고침 · 공유에도 유지 | 새 공통 컴포넌트 |
| 운용 모드 배지 | 시장별로 따로("국내 모의투자 · 자동" / "미국 모의투자 · 자동"). 한쪽만 실거래일 수 있다 | 기존 배지에 시장 라벨 |
| **장 상태 · 다음 실행 칩** | 국내 09:00–15:30 KST, 미국 09:30–16:00 ET = **23:30–06:00 KST**(서머타임 22:30–05:00). "장 마감 · 다음 실행 06:05" 식으로 다음 실행 시각을 한국 시간으로 | 새 공통 컴포넌트. 미국은 결정 · 체결이 한국 밤에 돈다 |
| 통화 포맷 | 국내 `₩` 정수, 미국 `$` 소수 2자리. 수량은 둘 다 "주" | `won()` 포맷터를 시장별 포맷터로 |
| 종목 표기 | 국내: 한글명만(지금과 같음). 미국: **한글명 + 티커 병기**("애플 AAPL") | 한글명표는 코어가 추가 중 |
| 국면 배지 | "KOSPI vs 200일선" → 시장 지수명으로("S&P 500 vs 200일선") | `benchmark_name_ko` |
| 청산 사유 · 매도 사유 배지 | 변경 없음(시장 무관) | |
| **색 관례** | 국내 빨강=상승 · 파랑=하락. 미국식은 반대(녹색=상승). → **열린 질문 Q1** | |

## 2. 화면별 변경

### 화면 1. 오늘 요약 (홈)
- 상단에 **시장 요약 카드 2장**(국내 · 미국): 평가액(각 통화), 오늘 손익, 드로다운, 운용 모드, 다음 실행 시각. 두 시장을 한눈에 보는 유일한 자리. 합산 금액은 넣지 않는다.
- 나머지 영역(오늘 자동 실행 · 리스크 한도 · Protections · 예외 큐)은 선택한 시장 기준. "오늘"은 그 시장의 거래일이다(미국 결정일은 미국 거래일, 한국 날짜와 하루 어긋날 수 있음 → 날짜에 시장 시간대 표기).

### 화면 2. 종목 선별
- 규칙 임계값이 통화별로 다르다: 가격 하한 1,000원 / $5, 거래대금 상위 N의 단위.
- 유니버스 라벨 "S&P 500 표본 40종목"(국내 "KOSPI 대형주 40종목"과 대칭). 섹터는 GICS 11개로 같다(한글 라벨 재사용).

### 화면 3. 결정·실행
- 체결 예정 시각을 두 시간대로: "체결 예정 11-14 23:30 KST (11-14 09:30 ET)".
- 하드룰 개입 문구의 금액 단위 `$`.
- 예외 큐에 미국 전용 사유 추가 후보: LULD 거래정지, 데이터 지연(새벽 캐시 갱신 실패), PDT 규칙 저촉(마진 계좌 $25,000 미만).

### 화면 4. 종목 상세
- 티커 · 거래소(NASDAQ/NYSE) 표기, 가격 `$`.
- 참고 정보로 **다음 실적 발표일**(미국 대형주는 실적 갭이 커서 손절이 못 막는 손실의 주 원인 — docs/05 교훈 1과 같은 맥락). 프리 · 애프터마켓은 쓰지 않는다고 명시.

### 화면 5. 포지션·리스크
- 장부가 시장별로 따로다: 현금 · 노출 · DD 게이지 · Protections · 가드 이력 전부 선택한 시장 기준. 통합 뷰 없음.
- 손절가 · 트레일링 고점 · 만료일 표기 통화만 바뀐다.

### 화면 6. 성과·백테스트
- "포트폴리오 실측" 탭에 **3차(미국) 실측** 추가 + 국내 2차와 **나란히 비교표**(드로다운 · 수익 · 거래 수 · 청산 사유 분포). 벤치마크 S&P 500, 급락 구간표는 미국 사건(2024-08, 2025-04 관세, 2026 구간).
- 데이터: `data/results/paper_us/summary.json`(core 작업 산출물), 계약은 `/api/paper?market=US` 예정.

### 화면 7. 설정·감사 로그
- "KRX 시장 상수" 패널 → **시장별 2개**: 국내(가격제한 · VI · 거래세) / 미국(LULD · SEC fee · FINRA TAF · T+1 · PDT · 장 시간).
- 자동 실행 한도를 시장별 · 통화별로(일일 주문 상한 1억원 ↔ $?, 주문당 3,000만원 ↔ $?). 값은 실거래 자본과 같은 원칙으로 **사용자 설정** → **열린 질문 Q3**.
- "실거래 자본 · 유니버스" 입력도 시장별. 미국 유니버스 선택지: 표본 40 / S&P 500 / 직접 지정. 미리보기("살 수 있는 종목 n/N")는 `$` 종가 기준.
- 운영 기록 · 규칙 변경 기록에 시장 열 추가.

### 화면 8. 모의투자 검증 (§11-1)
- 스코어카드 · 드로다운 게이지 · 위반 목록 · 전환 버튼 **전부 시장별**. 미국 모의투자도 따로 8주 기준을 통과해야 그 시장만 실거래로 넘어간다. 전환 모달에 "국내 모의투자는 영향 없음" 같은 범위 문구.

### 긴급 정지 모달 (KillSwitch)
- 정지 범위 선택: **이 시장만 / 전체**. 재가동도 같은 범위. → **열린 질문 Q2**.

## 3. 데이터 · API 계약에 미치는 영향 (api 워커 다음 작업, 참고)

- 모든 읽기 API에 `market=KRX|US` 파라미터(기본 KRX). 기록 파일은 시장별 디렉터리(`data/audit/<market>/`)로 분리해 장부가 섞이지 않게.
- `/api/labels`에 시장별 통화 · 지수명 · 색 관례 · 장 시간. `/api/health`의 "KRX" 고정 표기 제거.
- 운영 상태(`trading_state`)가 시장별로 재생된다(정지 · 모드가 시장 단위).

## 4. 결정 사항 (사용자 결정 2026-11-13 — "전부 권장으로")

| # | 질문 | 결정 |
|---|---|---|
| Q1 | 색 관례 | **앱 전체 국내식 통일**(빨강=상승 · 파랑=하락). 미국 화면도 같다. 한 사람이 두 시장을 보므로 혼동이 더 크다. 설정에서 전환하는 옵션은 나중 |
| Q2 | 긴급 정지 기본 범위 | **전체 정지 기본**, 모달에서 "이 시장만" 선택 가능. 재가동도 같은 범위 선택 |
| Q3 | 미국 자동 실행 한도 달러 기본값 | **일일 주문 상한 $70,000 · 주문당 $20,000**(국내 1억 · 3,000만의 1/1,400 근사). 사용자 설정값이며 기본값일 뿐 |
| Q4 | 미국 종목명 표기 | **한글 + 티커 병기**("애플 AAPL"). 국내는 한글명만 유지 |

## 5. 하지 않는 것

- 환율 환산 · 두 시장 합산 지표 · 통합 노출 한도(별도 포트폴리오 결정).
- 프리 · 애프터마켓, 옵션 · ETF 레버리지, 분수 주식(모의에서 쓰지 않음).
- 미국장용 하드 룰 수치 조정 — 3차 실측(docs/07)으로 기본값 결과를 먼저 보고 사용자가 정한다.
