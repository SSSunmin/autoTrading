# 4차 실측 — 유니버스 편향 (고정 40종목 vs 시점 지수 구성)

작성 2026-11-13, core 워커. 숫자만 적는다. 기본값이나 권장은 정하지 않는다.
US(S&P 500, §2 · §3)와 KRX(KOSPI200, §4) 두 시장. KRX 구성은 KRX 정보데이터시스템 수동 다운로드 스냅샷 6장이다. `^KS11` 교차 검증은 §5.

## 1. 무엇을 바꿨나

- 2 · 3차 실측의 후보는 **지금 고른 고정 40종목**이다. 기간 중 지수에서 빠지거나 상장폐지된 종목은 처음부터 후보에 없다(생존 편향).
- 4차는 리밸런스마다 **그날의 지수 구성**(`universe.members_on`)을 후보로 쓴다. 후보 = 그날 구성 ∩ 그날까지 시세가 있는 종목. 선별 규칙 · 하드 룰 · 비용은 3차와 같다(`RiskConfig` · `ScreenConfig` · `MARKETS` 값 변경 없음).
- 편출된 종목: 보유는 유지하고 규칙 청산(손절 · 트레일링 · 만료 · 등급 하향)만 받는다. 다시 사지 않는다.
- 시세가 끊긴 보유 종목: 첫 빈 날에 마지막 종가(− 슬리피지 0.05%)로 `delisted` 청산.
