# 진행 상황 · 인수인계 (2026-11-13 기준)

다른 세션에서 재개할 때 **이 문서부터** 읽는다. 세부는 각 문서로 링크한다.

## 1. 한 줄 요약

LLM 에이전트가 펀드매니저 사고 흐름대로 판단해 매수·매도까지 하는 **실전 자동매매 시스템 + 대시보드**를 만들고 있다. 코어(TradingAgents 추출) · 선별 · 하드 룰 · 감사 기록 · 백엔드 API · 프론트 7화면이 있고, LLM 에이전트 연결과 실행 레이어(실제 주문)는 **아직 없다**. 2차 실측으로 하드 룰이 드로다운을 −43% → −19%로 가두는 것을 확인했고, 다음은 모의투자 기간이다.

## 2. 사용자가 정한 방향 (바꾸지 말 것)

- 운용사 없이 일반인이 바로 쓰는 시스템. **LLM이 펀드매니저처럼 판단해 매수·매도까지 한다.** "LLM은 애널리스트만" 식 보수 제안 금지. 하드 룰은 LLM 불신이 아니라 리스크팀 가이드라인 재현으로 프레이밍.
- 기본 운용 모드는 **자동 매매**(기획서 v0.3). 단, 실거래 전 **모의투자 기간**을 거친다(사용자 명시 합의 2026-11-13). 코드 기본값은 `paper`.
- 종목명·근거 문구는 **한글**. 아티팩트가 아니라 **서비스**(프론트+백엔드).
- 역할 분담: **디자이너 시안은 다른 세션**(`mockup/canvas/project/*.dc.html`, v0.4 진행 중). 프론트·백엔드는 개발 세션이 만든다. 디자이너가 기획서(`docs/02`)를 고치므로 **작업 전에 §9 변경 이력과 파일 mtime을 먼저 확인**한다.
- **미국장은 국내장과 섞지 않는 별도 포트폴리오**(별도 현금 · 별도 노출 한도 · 환율 없음, 사용자 결정 2026-11-13). 시장 설정은 `config.MARKETS`.
- 모든 산출물은 `D:\trading-core` 안에. 커밋은 사용자가 요청할 때만, AI 서명 trailer 금지. "됐다"는 실행·테스트 결과와 함께만.

## 4. 핵심 측정 결과

- **1차**(`docs/03`): 20종목 × 8주 결정 단위 알파. 파이프라인 무결 완주, 통계 결론 없음(등급당 n=12).
- **2차**(`docs/05`): 40종목 × 2024-01~2026-11 포트폴리오. 최대 드로다운 KOSPI −44.9% / 하드 룰 끔 −42.7% / 켬 −19.3% / 켬+국면 −15.6%. 수익은 +100% / +193% / +67% / +80%.
  - 교훈 1: **손절은 갭을 못 막는다**(−8% 손절에도 −20% 거래). 손실을 가둔 건 **종목당 10% 상한**.
  - 교훈 2: 국면 필터는 드로다운·수익 둘 다 개선 → 기본 켬.
  - 교훈 3: 룰 켬 −19.3%는 −20% 정지 바로 위. 지금 같은 국면이면 모의투자 기준(−10%)을 못 넘기는 게 정상이고, 그러면 실거래로 가지 않는다.
  - 미검증: yfinance `^KS11` 2026-07-31 +17.9%가 같은 날 40종목 평균 +6.1%와 어긋남. KRX 공식 지수로 교차 확인 필요. 나머지 급등락일은 종목과 일치.

## 5. 실행 방법

```bash
cd D:\trading-core
uv venv --python 3.12 .venv && uv pip install --python .venv -e ".[dev,api]"
.venv\Scripts\python -m pytest -q                                   # 126 passed
PYTHONIOENCODING=utf-8 .venv\Scripts\python scripts\baseline_krx.py # 1차: 선별·결정·정산 기록 생성 (네트워크)
PYTHONIOENCODING=utf-8 .venv\Scripts\python scripts\paper_backtest.py # 2차: data/results/paper/summary.json
.venv\Scripts\python -m uvicorn backend.main:app --reload --port 8000  # http://127.0.0.1:8000/docs
cd frontend && npm install && npm run dev                          # http://localhost:5173 (/api → 8000 프록시)
npm run build && npx oxlint
```

환경변수: `TRADING_DATA_DIR`, `TRADING_MEMORY_LOG`, `TRADING_CORS`, `TRADING_ADMIN_TOKEN`(설정 시 재가동·모드 변경에 `X-Admin-Token` 필수). `~/.npmrc`에 `@bv-ds` 레지스트리 토큰이 있다. **토큰을 커밋·하드코딩하지 말 것.**

## 8. 함정·주의

- Windows는 대소문자를 구분하지 않는다. `App.css` 삭제가 `app.css`를 지운 적 있음. 파일명 충돌 피할 것.
- Git Bash에 `cp`·`python`이 없다(`cat a > b`, `.venv/Scripts/python`). 콘솔 한글은 `PYTHONIOENCODING=utf-8`.
- 프론트 `useApi`는 deps 간접 전달이라 oxlint 경고를 주석으로 끈다. 훅은 `src/hooks/`에만(App.tsx에서 export하면 fast-refresh 경고).
- `backend/main.py`의 상태는 저장하지 않고 `operations.jsonl` 재생값이다. 상태를 따로 저장하는 코드를 넣지 말 것.
- 2026년 5~6월 KOSPI 대형주 일 13~26% 급등은 데이터 이상이 아니다(검증됨). 변동성 상한 80%가 대부분을 거른 이유.
- 디자이너 세션이 `docs/02`와 `mockup/canvas/`를 동시에 고친다. `mockup/`은 건드리지 않는다.
